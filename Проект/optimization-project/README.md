# Відновлення цифрового зображення методами оптимізації

**Базовий практикум · Варіант 15 · C++17 · НТУ «ХПІ»**

Параметри: seed `223514`, гаусів шум `0.1756`, зображення `128×128`. Чисте зображення **генерується кодом** `clean_image()` у `src/image.h`, не читається з PNG. Файли PGM — тільки вихідні результати.

## Запуск

```powershell
g++ -std=c++17 -O2 main.cpp -o main.exe
.\main.exe
```

Програма має меню. Запускайте потрібний пункт окремо; він перезаписує відповідні CSV/PGM у папці `outputs`.

## Основні пункти

- `1` — результати лабораторної №2; `21` — таблиця Свенна й експерименти лабораторної №1; `22` — журнал і експерименти лабораторної №2 (точність 1e-6 та delta=epsilon).
- `2` / `3` — Нелдер–Мід / Пауелл; `4`–`7` — їхні досліди.
- `10` — оптимізація λ: **λ₀=0.6548, Δλ=0.2, межі [1e-4, 50], точність 1e-3**. `11` — еталонна енергія; `12` — шість градієнтних методів; `13`–`15` — досліди.
- `16` — сире спостереження; `17` — проєкція; `18` — штраф; `19` — досліди штрафу з перевіркою критерію; `20` — FISTA; `23` — безумовний розв'язок та кількість недопустимих пікселів.

Параметри λ та експериментальні координати **обчислюються** з даних; вони не записані константами. Контрольний пошук дає λ ≈ 0.62700927, E* ≈ 193.04147383.

Для множника штрафу `growth=2` використано ліміт 40 зовнішніх ітерацій, фактично критерій `rP<=1e-8` виконується за 29; для `growth=10` і `100` залишається ліміт 7. Внутрішня межа 100 ітерацій.

**Армійо:** прибрано обмеження пробного кроку 2/L; у тесті 200 ітерацій градієнтна норма ~1.84e-6 (критерій 1e-6 не досягнутий), тому статус «не збігся» залишено правдиво.

**Зауваження:** операції на всіх 16384 пікселях та перебір параметрів білатерального фільтра можуть тривати довше за інші меню. Після зміни коду старі CSV потрібно перегенерувати.
